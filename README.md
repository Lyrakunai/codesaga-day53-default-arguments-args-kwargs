## 🧠 What I Learned

- How `*args` collects positional arguments into a tuple.

- How Python matches arguments with parameters.
- How to design flexible functions that handle different inputs.

## 🔑 Key Concepts
- Default values act as fallbacks.
- `*args` → Tuple
- `**kwargs` → Dictionary
- Parameter order affects argument binding.
- Parameters after `*args` are keyword-only unless otherwise defined by the syntax.
- Flexible parameters make functions adaptable to different inputs.
